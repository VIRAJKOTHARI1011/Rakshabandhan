RAKSHA BANDHAN SISTER WEBSITE

Files:
- index.html
- style.css
- script.js

HOW TO USE:
1. Extract the ZIP.
2. Open index.html in Chrome/Safari.
3. Click "Play Music" to start the background audio.
4. Replace the placeholder images with your own sister/brother photos.
5. Replace the placeholder text in index.html.

AUDIO:
The demo currently references an external SoundHelix MP3.
For a song you have permission to use, put it in this folder as:
music.mp3

Then replace the audio source in index.html with:
<source src="music.mp3" type="audio/mpeg">

IMPORTANT:
Browsers normally block automatic audio playback with sound. The Music button intentionally starts it after the visitor taps.

BEST CUSTOMIZATION:
Replace the first hero photo, the story photo, all gallery photos, and final photo with your own sibling pictures. This will make the page feel like a personal digital Rakhi card.
